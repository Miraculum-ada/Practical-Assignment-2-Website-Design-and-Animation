# Практическая работа №2 — семантика HTML5

## Состав проекта

- `index.html` — страница с каркасом HTML5, `lang="ru"`, метаданными и семантическими областями.
- `styles.css` — адаптивное оформление для широкого и узкого экранов, видимый индикатор фокуса и режим уменьшения анимации.
- `images/hero.svg` — собственная векторная иллюстрация с доступным текстовым описанием.

Откройте `index.html` в браузере. Для публикации загрузите содержимое папки проекта в новый репозиторий GitHub и включите GitHub Pages в настройках репозитория (Settings → Pages → Deploy from a branch → main → /root). Страницу также можно опубликовать перетаскиванием папки на Netlify Drop.

Для проверки откройте https://validator.w3.org/nu/ и загрузите `index.html` через вкладку File Upload. После публикации валидатор можно проверить по URL сайта.

## Структура

`header` содержит логотип и `nav` с основной навигацией. Единственный `main` включает приветственный `section`, раздел «О нас», раздел преимуществ с тремя самостоятельными `article`, иллюстрацию `figure` с подписью и дополнительный `aside` со справочными ссылками. `footer` содержит контактный адрес и копирайт. Заголовки идут последовательно от одного `h1` к `h2` и `h3`. Для изображения задан осмысленный `alt`; у документа установлены русский язык и мобильный viewport.

## Контрольные вопросы

1. `<!doctype html>` сообщает браузеру, что документ использует современный стандарт HTML, и включает режим стандартной отрисовки.
2. `lang` задаёт основной язык документа. Скринридеры используют его для правильного произношения, а браузеры — для языковых функций.
3. Семантические теги описывают назначение содержимого. Это помогает вспомогательным технологиям, поисковым системам и разработчикам понимать структуру; `div` сам по себе назначения не задаёт.
4. Иерархия заголовков показывает структуру разделов и помогает пользователям скринридеров переходить между ними. Уровни следует выбирать по вложенности, а не по внешнему виду.
5. `meta name="viewport"` задаёт ширину области просмотра и начальный масштаб на мобильных устройствах.
6. `nav` используют для значимого набора ссылок навигации: например, переходов по разделам сайта или к основным страницам. В этой работе в него входят ссылки «О нас», «Преимущества» и «Контакты».
7. `section` объединяет тематическую часть страницы, обычно с заголовком. `article` — самостоятельный материал, который может быть понятен и отдельно от остальной страницы.
8. `alt` кратко передаёт смысл изображения в контексте страницы. Для информативного изображения пишут содержательное описание; для чисто декоративного оставляют `alt=""`.
9. Валидатор часто находит незакрытые или неправильно вложенные элементы, пропущенные обязательные атрибуты, повторяющиеся `id`, некорректные значения атрибутов и ошибки структуры документа.
10. Блочные элементы обычно начинают новую строку и занимают доступную ширину. Строчные располагаются внутри строки рядом с текстом и обычно занимают только необходимое место. В HTML точное отображение также зависит от CSS.

## Скриншоты и ссылка на публикацию

Скриншоты страницы можно сделать после открытия `index.html` в браузере: снимите общий вид страницы или отдельно шапку, основной блок и подвал. Публичная ссылка появится после загрузки проекта на GitHub Pages или Netlify.
